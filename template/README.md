## 使用说明

1. 每个模板文件包含完整可运行的 `main()` 函数
2. 部分模板提供多种实现/优化版本
3. 文件名格式: `中文名_英文名.cpp`，便于查找
4. 根据题目需求调整数组大小 `N` 和其他常量
